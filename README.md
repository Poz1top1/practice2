# Практическая работа № 2 — консольный калькулятор

## Описание
Консольный калькулятор на Python. Программа выполняет сложение, вычитание,
умножение и деление. После каждой операции можно продолжить вычисления без
перезапуска программы.

## Возможности
- Выполнение нескольких вычислений подряд.
- Поддержка операций `+`, `-`, `*`, `/`.
- Проверка некорректного ввода чисел.
- Обработка неизвестной математической операции.
- Защита от деления на ноль.
- Проверка ответа на вопрос о продолжении работы.

## Запуск
Требуется Python 3.

```bash
python main.py
```

## Пример
```text
Консольный калькулятор
Поддерживаемые операции: +, -, *, /
Введите первое число: 10
Введите операцию (+, -, *, /): *
Введите второе число: 5
Результат: 50
Хотите выполнить ещё одну операцию? (да/нет): да
Введите первое число: 100
Введите операцию (+, -, *, /): /
Введите второе число: 4
Результат: 25
Хотите выполнить ещё одну операцию? (да/нет): нет
Работа программы завершена.
```
